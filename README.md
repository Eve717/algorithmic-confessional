# Algorithmic Confessional / 算法告解室

**A browser-based interactive artwork that stages the extractive logic of surveillance capitalism as an intimate confessional ritual.**

**一个基于浏览器的互动艺术作品，将监控资本主义的提取逻辑以亲密的告解仪式形式呈现。**

🔗 **Live / 在线体验：** https://eve717.github.io/algorithmic-confessional/

---

## About / 关于这件作品

A user enters a simulated confessional booth — wood-panelled walls, candlelight, a glowing screen — and is invited to type their secret. The system responds with warmth, absolution, and encouragement generated by an AI language model.

用户进入一个模拟的告解室——木质墙壁、烛光、发光的屏幕——被邀请输入自己的秘密。系统以由AI语言模型生成的温暖、宽恕和鼓励作为回应。

What the user does not see: their words are simultaneously parsed for emotional keywords, assigned a market value, timestamped, and stored in a database. A receipt is produced. The transaction is complete.

用户看不到的是同时发生的事情：他们的文字被解析为情感关键词，被赋予市场价值，被打上时间戳，存储进数据库。一张收据随即打出。交易完成。

> *"By speaking, you have waived all rights to your internal silence."*
>
> *"你开口说话的那一刻，即已放弃了内心沉默的一切权利。"*

## Backend View / 幕后视角

The work has two faces. A hidden interface — accessed via a nearly invisible symbol at the bottom-right of the screen — presents all collected confessions as a dataset.

这件作品有两个面向。通过页面右下角几乎不可见的符号可以进入隐藏的管理员界面，将所有收集到的忏悔呈现为数据集。

- Emotion tags / 情感标签
- Keyword frequencies / 关键词频率
- Market valuations / 市场估值
- Typing durations / 打字时长
- Timestamps / 时间戳
